# LEARN-004 跨页长文遮挡

依赖 READ-001、FND-002。使用固定 DSH Host、真实 Chrome 和隔离 SQLite。P04 用至少三页的合成长 PDF，必须从浏览器实际鼠标跨页选择；只验证 API 或算法不能放行 P04。沿用 A07 的确定性 PDF 生成方式，使用编号长行、页缝两侧重复短语和各组唯一答案标记，从生成器独立预期每页边界与字节；保存实际鼠标拖选与持久化证据。

| 用例 | 操作 | 通过条件 |
| --- | --- | --- |
| LEARN-004-T01 / P04 | 从第一页中段拖选到第三页中段（选区超过短摘录长度），设置至少两个遮挡组，其中一组横跨分页。 | 各页 UTF-16 起止与固定原文、逐页哈希一致；跨页无缺页、重叠或截断。普通练习响应、DOM 和浏览器缓存无未揭示答案；分页不更改选区与组合。 |
| LEARN-004-T02 / P04 | 提示一个遮挡范围、揭示另一个，记录独立回忆与自评，停在非首页；关闭浏览器、重启 Host 并发布源材料新版。 | 复练回到原位置，分组、提示、揭示、独立回忆和自评分开保存。材料仍指向历史版本，变化需要复核，不自动迁移；新版不能伪装成旧答案。 |
| 权限 / 故障回归 | 猜 ID、撤销阅读许可、并发提交进度、重试同一操作；用已含笔记和引用的 v21 数据库注入迁移失败后重开。 | 私人练习与当前源 ACL 双重检查；不得以隐藏 UI 代替服务器挡住答案。拒绝失配修订；无部分写入、重复事件或旧数据损失。 |

结构化选择只保存固定 asset/version、适用时的固定 Word conversion、连续页段的 UTF-16 边界与源哈希；遮挡组只引用选区内页段。由服务器按目标版本重读，不保存另一份答案全文。分段渲染不限制资料可选范围；未解析的内部页必须提示补齐，不能跳过。A45 在 LIFE-003 的真实新版本影响链具备后补验，不算本单元自动通过。
