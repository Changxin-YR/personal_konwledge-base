# LEARN-003 独立验收预期

覆盖 T01、T02、P05 和 A14。基线为 18e65b3。主跑和独立复跑使用同一冻结候选，分别启动新隔离 DSH Host、Chrome、SQLite 与业务账号。用真实产品入口操作合成资料，模型调用为零。记录候选、构建、runner/夹具哈希、实际命令/退出、HTTP、浏览器状态和 SQLite 记录。

## 夹具

- 作者 O 在项目 P 内准备已核查的固定资料 V1 及真实 Reader 引用。普通成员 A、B 都通过实际入口取得独立的项目和资料读权限，在各自独立 Chrome context 作答。另有不相干的项目成员 C、独立对照题及无争议领域。
- 主选择题根据原文应为「三次」，O 误设「两次」。A 首次选「三次」得错，B 首次选「两次」得对，两人都有相同题目/题版且明确有把握、未提示。另备独立的四类题，用于答对不确定、提示后答对、提前揭示后答对和有歧义的开放表达。记下两人的帐号学习方向、领域、目标、规划服务、修订号、现有个人复习项和能力结论。
- 用契约中的个人错题、题目状态、能力结论、提示、揭示、争议和题目修订入口。SQLite 比对以独立只读连接观察；故障测试只在隔离副本写故障注入。

## T01 / A14 两人同题、个人记录与纠正

1. 从实际共用题及答题页让 A、B 分别提交首次答案。核对 A 的错题、首次时间、题版、个人状态和正式作答证据；B 的同一题正确有自己记录，未进入 A 的错题或因 A 答错被加入 B 的错题。A 为这一题编辑错因并设置复习状态/时间；B 的状态与复习安排不变。A/B/C 用已知 ID 尝试读写他人的会话、错题、评价和纠正入口，均失败且无数据副作用。O 的题目管理权限不等于读取 A/B 私人错因或作答。
2. O 从实际题目修订入口将标准答案纠正为「三次」，记录固定证据、原题版、作者、时间及理由。重放同一键返回同一修订，改变请求或竞争同一预期版本最多成功一次。题目当前版本前进，原版本答案、解析和 A/B 原作答字节不变。新会话使用新题版；旧会话与反馈继续回读原版，但明确标记历史/原判语义，不能把旧证据静默绑定到新题版。
3. 对同一对 V1 独立尝试重算受影响的当前评价。A/B 的旧结论保留，新的当前评价以明确的纠正版、规则和原尝试引用替代旧评价。此夹具应该使 A 当前结论转为正确、B 转为错误，同时原始判分事实仍分别为错和对。个人当前错题按重算结果更新，原错因历史仍可追溯，不复制给另一人。无关题、领域、复习进度以及他人账号数据不变。若采用待重算状态，应在真实入口触发并最终验证已完成的新评价。
4. 刷新及 Host 重启后核对两人的独立错因/复习、当前题版和评价、旧尝试/评价链及固定源。撤掉某人的来源/项目权限后，答题、争议、评价、计划、前台及重放不能读到受限证据；另一人有权路径正常。记录权限取消不删除需保留的历史行。

## T02 / P05 四类表现、争议与后续计划

1. 从实际 Reader 快答链打开可追溯材料，并由真实题目、会话和个人页面呈现四类表现。A 独立确信答错；答对但选择不确定；先显式取提示后答对；在自身练习内报告固定源存在的歧义。使用有证据的清晰题验证对照，开放表达产生的 disputed 不能被当成错题。四种展示、API 原因和个人状况分开。已确认的正式错题只归 A，B 列表及自己的复习不变。
2. 未使用帮助时的 GET 及初始 DOM 不含答案。应用实际提示、再提交正解，验证提示先持久化、作答引用帮助手段，结果标记辅助完成且未计独立掌握。如果在第一次提交前显式使用「揭示」，要记录揭示并强制以后答为非独立；没有该帮助动作的正常首次提交仍先持久化再返回解析。先作答再取提示不可倒改先前尝试的独立性。无权或伪造会话的提示与揭示都无答案，幂等多次不会重复登记。
3. 提交歧义报告后，实际页面可检查自己的报告、源和待处理状态。存储证据显示相关题版/尝试暂不参与正式评价，既有受影响的当前结论暂停或追加替代版本，不重写旧结论，不把待复核作答当错题。授权作者可查看题目争议所需证据和纠正题干/标准，不获得普通用户全部错因或资料。报告重放和竞争无重复或越权。
4. 打开实际后续复习计划或个人复习入口，看到本人当前的待复习项/时间和下次可行动项，区分已纠正、辅助完成及争议暂停。对照 B 的计划无 A 的条目。逐步比对 A/B 的 /me 返回及 SQLite 个人资料的 domains、learning_tracks、goal_text、planning_home_service_id、revision 和更新戳。答错、重答、加入复习及报告争议均不得自动改变学习方向。若产品提供方向建议，必须独立处于待本人确认并拒绝他人代签。
5. 对 SQLite 事务注入回执、状态或评价写入故障，证明纠正、题目当前指针、个人修订与评价发布一致，失败不留下半完成结果。追加迁移从有题、会话、尝试和快答来源的冻结 v40 入库验证，故障回滚前态，正常重启保留旧数据和外键。

P05 的完整证据需要实际观察后续个人复习路径、四类状态和方向保持。只有 T01/T02 或 API 结果不能替代 P05。全量「今日计划」与复习预算属于后续单元，分层提示、延后复测和等难度迁移仍由 LEARN-005 完成。A14/P05 通过不自动关闭 F23、F44 的其他完整案例。
