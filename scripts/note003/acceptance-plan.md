# NOTE-003 大纲与脑图验收计划

以通过 NOTE-002 的提交为基线。使用真实隔离 DSH Web Host、Chrome 和 SQLite；两个并行页面使用同一个业务账号和同一笔记，另用独立账号检查权限。仅使用合成原件和账号。

## T01 与 A17：同一个树的双向操作

1. 同时打开大纲与脑图。从大纲创建至少三级节点，从脑图创建、编辑和移动节点，再从大纲编辑脑图节点。已确认提交应在另一个无草稿的视图无需重载即出现；逐项比较页面、HTTP 和 SQLite 的节点 ID、正文、父子、同级顺序及修订，不得复制节点。
2. 从脑图删除带至少一级后代的节点：先预览，取消无写入，选择提升或子树回收后两个视图一致；从大纲撤销，原节点 ID 与正文恢复，固定原件不受影响。
3. 一端保留正文草稿，另一端提交同一节点的新正文。迟到写入拒绝，明确读取最新版本后同时保留服务器正文和本地草稿，不能自动重放移动、删除或正文保存。其他账户的详情和修改不可用。

## T02：布局与内容隔离

1. 选择脑图横向和纵向布局。画面中的节点和连线按实际树层级变化；布局只变自己的修订，不改变笔记修订、正文版本、节点行或原引用。错布局修订拒绝，正文提交仍按正文修订判断。
2. 刷新、重启 Host 并使用新 Chrome 上下文重新登录，验证布局、相同节点 ID、来源版本和原件摘要均恢复。保留不同尺寸截图，检查地图滚动与节点控制可操作。
