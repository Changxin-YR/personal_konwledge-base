基线 `5ee23801afd70276e8e18e4b132b9bf54adf67ce`。以下是测试预期，不是通过记录。

- T01：在真实浏览器打开一个有重复段落的合成文档，选中第二处的子串并生成引用。通过解析接口和新的浏览器页面打开引用，核对固定资料及版本、页或结构块、半开字符区间、原文与选区高亮。包含非 BMP 字符、换行和相同文字的两次出现；不能依赖全局首次文本匹配。PDF 原页同时显示源页面与可对应的文本层坐标。Office 转换引用须绑定具体结果，不随下一次转换变化。
- T02：有一部分页已就绪、一部分仍未解析或已失败时，只请求当前窗口的内容。明确区分未解析、加载失败、原文变化和撤权；恢复后重试相同版本及页段。在同一资料上添加新版后，旧引用仍指向旧版。匿名、另一账号、撤权后不得获得原文摘录、页图或坐标。
- 数据：沿用现有文本块的半开 UTF-16 偏移；不允许偏移落在代理对中间。保存及解析时依据服务端固定版本重新校验文本与锚点。不保存客户端提供的 actor、原文或可替换的任意文件 URL。
- 留证：小样本原件及哈希、真实 Host/Chrome/SQLite、原页截图、滚动窗口请求、历史版本回读、撤权负例和独立复核。这个单元只覆盖 P02/A09/A45 的相关步骤，不代表完整大 PDF、搜索或最终场景通过。

## Word 源结构回归

- 单一源段落无显式换行，固定 PDF 至少折成两行。首词、尾词、整段引用的源块 ID 与两侧段落邻锚一致；同一资产版本重新转换后，源块 ID 不变，旧引用仍绑定实际旧转换的页和坐标。
- 不同段的同文按源顺序区分；跨段选择记录多个源区间；自然跨页的同一段保持 ID，源 UTF-16 偏移与页内高亮各自独立。结构与固定 PDF 不一致时不生成猜测定位。
- 经真实 Host 验证固定上游的二进制 Word 97 夹具，不能用改扩展名的 DOCX 替代。另保留 XML、失配和不支持结构的专项负例。
