# LEARN-005 独立验收预期

覆盖 T01、T02 和 A15。以 a70ecfa 为基线，在同一冻结候选用独立隔离 DSH Host、Chrome、SQLite 和合成账号完成主跑与复跑。本轮不调用模型。记录退出码、候选/构建/runner/夹具 SHA、实际响应、截图、时钟、保存记录及外键。长期能力汇总和全量日计划仍按各自工作单元验收。

## 固定资料和时钟

- 项目作者 O 提供经原文核查的选择题 A0，以及相同类型/难度/判分规则但题干、选项和固定来源不同的迁移题 B0。A0 考查「发生连续采样失败后按计数上限停止重试」，B0 改用日志转发失败场景和另一限次。原文分别有唯一标记。另备不同题型、不同难度、无核查来源、已暴露答案、源权限即将撤销以及待争议的对照题。记录题目、题版、实际规则、证据 ID、原件版次、坐标/哈希。没有可核查的同难度条件时不得宣称已匹配。
- 普通成员 U、V 用独立 Chrome context 加入项目，分别获原件访问权。OID、题版和计划 ID 即使已知也不授予任何私人记录权限。隔离时钟固定 T0，使用明确晚于 T0 且会话仍有效的 UTC 到期时间 D。相同业务时钟驱动界面/API/SQLite，区分 D-1 毫秒和 D。

## T01 / A15 首答、两级提示与迁移

1. U 从实训界面开启 A0。无提示、未看答案、有把握地首次提交错误选项。API 响应到达后独立连接已读到不可变首次错误、提交时间、尝试序号和无帮助标记。首答前整个页面和业务 DTO 不含解答。分层训练首答后只提供正常的作答反馈或后续操作，不提前显示完整参考答案。如果传统答题已展示解答，应独立记录这种暴露，后续不能归为仅提示后的完成。
2. U 在同题首次错误后分别显式请求第一级和第二级提示。第二级在第一级之前不可取得，两个级别帮助内容不同，提示事件按顺序、系统时间和使用者入库。相同键精确重放各返回同一事件，改级别/题版同键或跳级请求不新增。请求提示不会改写初答事实、版本、首次提交时间和独立性。U 在引导下提交正确答案，看到独立于首答的新尝试及相应提示来源，标签为辅助完成且不能替代独立首答或计作独立掌握。选择显式揭示的对照要与仅提示清楚区分。
3. U 在真实入口保存自己的延后迁移计划，页面显示准确到期 D 和相同难度迁移条件。在到期前不泄露迁移题面、选项、答案或隐藏来源。旧题、其他题型、难度不合、已暴露内容、质量不足及无权候选均不能悄然替换为等难度迁移。V 看不到也不能操作 U 的计划。
4. 将时钟推进到 D-1 毫秒尝试开启，必须还未到期且不创建迁移会话。正好 D 通过同一路径开启成功。并发点击或丢响应重放也只有一个对应迁移会话。新的固定 B0 不是 A0 或 A0 的另一选项顺序，难度及规则确实匹配。U 在 B0 不看提示、不提前揭示，作答正确，得到独立迁移记录且来源跳转到 B0 的固定原件。三个尝试分别对应「原题独立错误」「原题提示后正确」「新题独立迁移正确」。评价界面保留互相独立的事实及强度限制，不把辅助成功或单次迁移解释为确定掌握全领域。
5. 刷新、重输幂等键和实际重启，确认三类尝试的 ID、顺序、相同固定证据、提示及 D 连续。题目源改版后，保留授权内旧证据定位，不将旧答静默绑定新版本。

## T02 缺失、低质量、失效及权限

1. 用固定反例验证无合适迁移题、不同难度或不匹配规则、曾见目标答案、无正式资格的生成练习、争议/无从核查的源以及未按规则独立提交。应用可继续明确标记练习或拒绝开启，评价显示缺少何种证据或暂停，不能生成正式达标、独立迁移成功或覆盖原首次结论。记录源、规则版本、状态和真实原因，不依赖泛化文案。
2. 为 U 单独建立可核查对照计划，等待期间撤销源读权限但保留项目资格。推进到 D 后，用旧页面、深链接、真实接口和成功幂等键重放，测试拒绝/清屏及受限内容零泄露。对原题和迁移题的独立授权分别测试。对另一计划在预约后打开题目争议或纠正规则版本，要求旧票据不能当作新可靠证据，已有历史保留但当前正式资格受限。V 的无关权威路径仍可工作。
3. 检查无效/重复请求前后 SQLite 计划、会话、尝试、提示、评价及回执差异。错误或竞争失败不创建无依据的迁移结论。若本轮有追加迁移，使用冻结 v41 中真实已有题、首答、提示、复习和重判记录验证失败回滚、成功升级及再次打开后的行和外键。

只有用户真实经历「先独立错、分层帮助后答对、到期在另一等难度题独立完成」且各版本和来源可核查时，才记录 A15 通过。课题长期汇总和能力评估完整覆盖依照余下验收场景。
