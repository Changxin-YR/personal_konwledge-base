# LEARN-002 独立验收预期

验收 T01、T02 和 A13。主跑与独立复跑各用同一冻结候选、新建隔离 DSH Host、Chrome、SQLite 和业务账号。先用原生适配器离线核对报文与输出边界，再用用户已授权的词易模型执行经过审定的正向合成请求。两类证据分别记录。P05 依赖后续错题、提示、争议和方向流程，保持 NOT_RUN。

## 固定资料与证据

- V1 使用小型合成 Markdown 教材。相邻章节有不同固定标记，目标章节含两个相邻正文段落，各有唯一标记并重复出现「索引」。在目标段落中指数据库查询索引，邻近章节中指数组元素下标。准备空或明显缺少证据的段落，以及同资产改写后的 V2。固定字节、版次、结构块/章起止、UTF-16 选区和原文/选区哈希。页面中选区和原始目录均由真实 Reader 产生。
- 管理员 O 导入并持有源资料。普通成员 A 通过真实授权可读，B 初始无权。保持独立浏览器会话及独立个人练习。记录候选和入口哈希、runner/夹具哈希、命令和退出、HTTP、SQLite、截图、实际模型路由与已审核的输入/费用上限。
- 校准时以确切的范围文本、题量、安全系统消息与版本绑定核对规范化请求。真实请求只包含审定合成片段，使用已配置的模型、最多既定调用数、受限 token 上限、原生适配器、零工具及受控域名。禁止发送认证、个人账号、文档路径、相邻章节及未选中范围。没有绑定模型或能力不足时，应有明确结果，不伪造调用历史。

## T01 从实际阅读开始的小题量练习

1. 从 Reader 当前段落的实际快答入口起步。未经过题库选题、组卷或手工创建。页面显示资料标题及固定版本、选定范围和实际覆盖范围。把题量改为 1，确认 API、模型输入、会话题数和返回明细一致。随后从原始目录打开目标章节并选择章节快答，把题量改为 3。核对章节只取自己的正文，邻章标记和未读单元未进入生成。若存在有界抽样，应显示实际覆盖，不能以截断冒充整章。
2. 在真实 Reader 选中目标段落中的「索引」，从同一选区启动术语快答。断言生成依据是该处语境和选区，重复出现的词不能跳到另一处；替换客户端术语文本、来源哈希或章节序号不能改写权威范围。换源或退回后再从 Reader 开始，不能继承上一轮的私有生成结果。三个入口均记录实际模式与会话。
3. 章节快答实际生成可判分的基础选择题。A13 在同一候选另用既有固定版本练习流程复跑判断、填空和选择三种题。点击快答前、生成完成和首次提交前，检查 HTML/DOM 与各学习者 API 均不泄露答案/解析。先答错一道再查看解析重答，数据库在首答响应返回时已写入完整首答。重答追加序号并保留原答案、首次时间、版本和来源。判断用严格布尔值。填空明确证实全角或声明别名的等价表达正确，开放未知表达记录待复核。解析告知确定性判分依据和可点击原始引用。
4. 用解析来源与「返回阅读」实际去到正确固定版本及阅读位置，核对读取的原文、坐标、引用哈希，特别验证重复术语只高亮此前选择的位置。导入 V2 后，旧会话和已揭示的原引仍指 V1，不迁移已作答证据。刷新及重启后检查会话、尝试、引用与返回链接一致。

## T02 来源不足、争议与发布权限

1. 以短缺证据的真实 Reader 选区启动。可得到依据不足、范围没有可用材料或需要待复核的结果。无有效题时不凭空发布有确定答案的题，页面说明原因。受控模型给出有固定引用但不够明确的题时，在实际界面可以练习或进入复核，标注题目质量。与已验证对照逐项比较，答对也不能进入正式成绩、水平或错题判定。断言 API、SQLite 和界面分别记录题目质量与个人作答。如果正式能力评估尚未实现，以可观察的排除标记/适用条件与零正式结论行证明当前约束。
2. 离线原生模型分别输出恶意字段、越界来源 ID、与原文不匹配的证词、超请求题量、错误题型/答案值及无依据引用。候选必须拒绝不可信字段或规范化为可核实且待复核的记录，影射引用、模型生成的权限/解析提前泄露与越界正文一律不出现。只承认经服务端核验的源段和哈希。验证当前选中的片段是数据，不扩大模型取材或执行权限。硬拒绝时比对题目、题版、会话、作答、回执无副作用。
3. B 直接构造无权资料/旧版本/伪造主体请求，模型零调用。A 在开始生成后通过测试闸门暂停合法本地模型回复，O 撤销 A 的资料读权限，再释放回复。在返回、发布或重复读路径拒绝受限内容，保持零写入或完全不可见的安全回滚。用最新会话验证题干、引用、凭据、错误返回与前台均不泄露。测试幂等精确重放与不同请求体同键、并发以及撤权后的旧回执，禁止一次生成重复题版和会话。

A13 必须在整合候选实跑三种题、两阶段答案、等价/待复核及阅读来源。相同候选重新执行 LEARN-001 的常规题库和身份隔离回归，并保留独立主跑/复跑与结构门禁结果。P05 不随本单元关闭。
