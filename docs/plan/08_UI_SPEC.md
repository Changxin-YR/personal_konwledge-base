# 页面与交互规范

用户已确认的方向：简洁温润、偏冷的玉石青色、企业常用字体、适度圆角、最多两级导航。下列色值、尺寸和版式参数是实施默认值，可根据真实页面与可读性小幅调整。

## 1. 全局结构

左侧一级按钮只保留六个工作区：今日计划、知识库、笔记、项目协作、智能讨论、管理与设置。点击后，主内容区域全部属于当前工作区；二级入口在当前工作区标题下展开。详情、编辑、阅读与审核是当前模块内的页面，不再增加第三套永久导航。

避免将独立知识列表、聊天、任务列表同时并排常驻。资料阅读可打开目录或辅助工具面板，窄窗口下使用抽屉，并优先只展开一个。AI 助手按需展开，默认不挤压正文；它显示本次使用的资料、范围、版本和权限。

顶部统一提供个人/项目范围、搜索、创建和消息。路径与内容权限要一致：切换到一个项目，不允许残留上一私人空间的标题、缓存摘要或搜索建议。

## 2. 视觉默认值

| 项目 | 实施默认值 |
|---|---|
| 字体 | `Segoe UI`, `Microsoft YaHei UI`, `PingFang SC`, system-ui；正文不使用艺术字 |
| 正文 | 14–16 px；中文阅读行高 1.6–1.8；长文宽度约 720–920 px |
| 主色 | `#3D7E86`，用于选中、主要操作和强调；避免大面积鲜绿 |
| 浅色底 | `#F5F7F8`；卡片 `#FFFFFF`；主字 `#23333A`；次字 `#66777F` |
| 深色底 | `#161E24`；卡片 `#202B32`；主字 `#E6EEF1`；强调色调亮以保持对比 |
| 圆角 | 输入/按钮约 6–8 px，普通卡片 10–12 px，重要弹窗 12–16 px |
| 间距 | 4/8/12/16/24/32 px 等级，靠留白和线条组织层次 |
| 状态 | 完成用低饱和绿，待审用蓝灰，提醒用琥珀，失败用柔和红；文字/图标共同表达 |

状态颜色不等同操作主色。使用真实文本、禁用态和焦点框，不能只靠颜色区别。正常/悬停/选中/禁用/加载/错误均有表现；键盘可完成核心流程。

先验证 1366×768 和 1920×1080、100%/125%/150% Windows 缩放，长中文标题、空列表和大量数据不能撑坏布局。真实文字对比与字号需要在截图检查，不仅检查 CSS 是否含指定色值。

## 3. 六个工作区

| 工作区 | 首页 | 二级页面 |
|---|---|---|
| 今日计划 | 今日承诺、现在可做、复习、等待他人、评分原因 | 任务详情、执行记录、复习队列、评分依据、提醒记录 |
| 知识库 | 搜索/资料列表，固定显著四入口 | 资料阅读、术语、知识/本体、快答、题库/错题、遮挡、仓库、工程案例、正式方案 |
| 笔记 | 最近笔记、目录和编辑器 | 普通/读书/项目/复盘；大纲和脑图为同一内容的视图切换 |
| 项目协作 | 项目目标、任务进度、我的待办/待审 | 成员、任务、提交、审核、复议、协作记录 |
| 智能讨论 | 目标、阶段/轮次、当前候选稿、阻塞 | 意见、版本对比、投票、冻结、历史与用量 |
| 管理与设置 | 当前用户有权管理的操作 | 用户/权限、模型、插件、统计、通知、回收站、导出/备份 |

知识库首页固定：**专业术语、遮挡背诵、基础快答、错题复习**。不把这些能力只埋在右键菜单或聊天提示词中。

## 4. 阅读与训练

阅读页顶部显示来源版本、原页位置、解析范围和权限。选中任意文本出现：解释术语、记笔记、遮挡背诵、基础快答。操作结束保留阅读位置。

遮挡页提供原文范围与分组预览、逐段揭示、提示、独立回忆、自评、继续练习；跨页选择展示完整范围，不能无提示截断。资料版本变化时保留旧练习并要求核对重定位，不能直接漂移到新版本的别段文字。

快答先显示范围和题量，提交时先保存首次答案再展示解析。题目有争议、来源失效或使用提示时清楚显示，不计入不符合条件的正式能力判断。

工程训练每步显示“自己的首次判断”“使用的提示”“证据”“当前结论”；没有实际测试时显示“待验证”，不能用绿色完成态把建议伪装成已修复。

## 5. 协作与评分

任务详情固定显示标准、负责人、截止时间、下一处理人、提交版本及审核记录。退回包含未达标准与需补材料；管理员派发任务的同伴通过状态仍为“待管理员终审”。

日评分显示等级、规则版本、任务/学习证据和待结算原因。C/D 是评分结果，不是人的标签。复议与改判保留旧结果和理由；历史提醒如依据已更正，显示更正状态。

强提醒没有关闭开关、紧急暂停按钮或 AI 禁用命令。展示规则与当前是否触发的原因，提供开始执行、拆分任务、寻求帮助和报告阻塞。用户可以关闭当前消息视图以继续工作，**关闭视图不关闭规则**；发送频率与结束条件始终由已确认规则控制。

执行任务显示预计结束时间与到期后的下一操作。不能只显示无限期“进行中”；报告阻塞需进入约定的认可流程，不能输入一个字就自动获得永久免提醒。

## 6. 智能讨论

候选稿版本与评审席位同时可见。每席显示正在评审、赞成、需修改、调用失败/超时以及依据；三席中两席赞成一席失败，页面仍为受阻。第五轮未通过展示最佳稿、分歧与用户裁定入口。

冻结是设计版本结果，旁边显示执行/任务状态；不能把投票通过显示为实际工程修复已验收。用量不明时显示“暂无可核实用量/价格”，不用零元填补未知。

## 7. 生命周期和异常

所有可持久动作有保存中、已保存、等待同步、失败可重试。离线时保留内容区域并显示连接状态，不用整页白屏替换已有工作。结果未知的提交提供“核对结果”入口，不鼓励无限点提交。

邀请码创建与兑换均显示绝对到期时间和剩余时间。恢复资料预览位置、重名、当前权限、引用关联与旧分享状态。永久删除预览影响并需具体确认；移除引用与删除原件是不同操作。

下载/导出显示内容范围及来源服务，用户可明确知道哪些私人内容会进入输出。拒绝访问时不泄露无权对象的标题、作者、命中数量或原文摘要。

## 8. UI 验收方式

用真实业务数据和状态覆盖核心页面，逐条走 P01–P14。保留浅/深色与缩放截图，检查文字截断、叠层、可点击区域、长文本、键盘焦点、错误后恢复和首屏关键入口。

此前原型图没有随当前仓库提供，不能声称已做到逐像素一致。按照本页和已确认需求实现可运行界面；最终视觉细节由真实页面截图供用户审阅。
