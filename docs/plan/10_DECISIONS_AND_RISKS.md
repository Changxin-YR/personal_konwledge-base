# 实施决策与验证门槛

本页中的技术默认值由实施方案提出，不冒称为用户原话。Codex 可以依据真实代码与实验调整实现手段，保留产品行为并记录理由，不为普通工程选择反复等待用户。

## 2. 仍需确定的可配置参数

- **ABCD 公式：** 用户确认要有等级和依据，没有给出完整加权公式。使用需求基线提出的可选默认值时必须展示、绑定版本并支持评审；正式数据不能在未告知规则的情况下被追溯扣分。按验收结果与承诺任务权重计算，不用键鼠时长判断努力程度。
- **提醒钟点：** 用户确认按约定学习/工作时段，未给本产品每日具体钟点。首次设置规划时段并明确展示；不得擅自套用实习作息或全天提醒。时段配置不能变成关闭强提醒的后门：有计划的工作/学习日必须有有效时段；修改留记录并说明生效范围。
- **执行时段：** 默认使用该任务本次计划的结束时刻；可提供合理短时默认值，但延长需要具体进度/计划更新，不能无限自动续期。
- **模型并发/预算：** 以实际 provider 和账户限制为基础，采用保守队列；不要编造固定免费 token。缺少价格只显示未知。
- **文件/压缩包限额：** 至少满足已确认 40 MB/730 页用例；额外展开大小、文件数和嵌套限额在配置中明确，并用超限测试证明错误可恢复。

这些参数可在 M0–M4 实施中形成产品默认值。需要用户选择的是实际个人偏好或影响既有承诺的规则变更；开发可以先用明确标注的测试配置继续。

## 3. 真实风险与对应门槛

| 风险 | 事实或设计原因 | 处理与验收 |
|---|---|---|
| 外部 Client 插件不能直接加载 | DSH 使用专有模块装载产物，构建 preset 依赖上游脚本 | M0 真加载与重载；不要用静态网页截图代替 |
| 多人泄露私人内容 | 默认浏览器/Desktop 认证共享 owner 语义，部分附件接口为存储级 | 独立身份/对象 ACL/非白名单路由拒绝，两个身份与撤权测试 |
| 安装后 SQLite/转换依赖失效 | 源码和 Electron 打包 Host 的环境不同 | 打包后持久化、转换、资源路径探针 |
| 强提醒通过普通插件被关闭 | 上游 Schedule 可停用，Host 插件能运行进程内代码 | 产品核心保护 + 管理API/AI工具拒绝关闭，可信插件名单 |
| 资料变动导致引用或评分漂移 | 来源可更新/删除/撤权 | 版本不可变、依赖失效事件、历史保留、当前可见性复核 |
| 模型调用失败被误计票 | 真实网络/额度不稳定 | 每席状态、冻结版本、完整分母、失败受阻和恢复测试 |
| 断网或进程崩溃重复提交 | 服务器与客户端不能总是同时知道结果 | 幂等键、命令查询、outbox、有限重试、unknown 状态 |
| 备份恢复复活旧分享或重复提醒 | 备份可能早于撤销/发送记录 | 恢复预览、当前授权复核、旧实例关闭、恢复后重新结算 |

## 4. 运行能力与信任边界

应用内不可关闭 F30，不包含拦截操作系统退出、关机或修改源码。可信 Host 插件有进程级能力；仅靠普通 ACL 不能隔离恶意插件。共享服务不接受普通成员安装任意 Host 代码，管理员安装新插件也要可核对来源与版本。

已下载到外部的文件不能因邀请码到期被远程抹除；产品应限制后续访问和导出，展示实际分享范围。离线保存个人草稿与继续访问已失效共享资料是不同问题。

## 5. 变更记录格式

每次调整写明：编号、日期、影响需求、旧决定、新决定、代码/实验依据、迁移影响、回退方式、需补的验收 ID。改变实现不必重新征求所有已给授权；改变用户已确认的行为需提出具体差异。
