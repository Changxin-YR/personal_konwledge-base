# 验证证据

证据以单一功能归档到 `docs/evidence/<unit_id>/`，例如 `FND-001/`。至少包括任务与instruction_revision、相关需求/验收、架构与测试预期、候选commit/文件指纹、实际命令/操作与退出码、环境、输入性质、失败与复测、独立复核、最终报告。

测试计划在编码前建立，边开发边跑，冻结候选后独立复核。测试计划和结果是证据，不是第二份启动指令；不能包含改变active_unit、跳过门槛或自动开启未来功能的命令。

每条PASS必须指向准确候选和实际运行证据。夹具、自制资料、真实模型、真实平台分开；单功能通过不自动使66个完整场景或44项需求通过。重新修改被测代码后，明确哪些证据失效并补相关验证。

公开仓库只存脱敏证据与摘要，真实教材、私人作答、模型密钥、会话令牌和未经授权项目源文件留在本机。旧证据保留其时间与范围，旧可执行指令只在Git历史中追溯。
