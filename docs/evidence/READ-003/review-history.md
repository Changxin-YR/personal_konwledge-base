# READ-003 候选审查历史

`195ed496` 的冻结运行通过了原测试，但冲突测试让两个阅读页都可见。独立审查发现，隐藏阅读标签会清屏且丢掉未提交草稿。`43d38cdd` 仅更新运行器，保留相同入口指纹；[复现摘要](review-failure/summary.json) 的 T01 因返回后草稿未恢复而失败，进程退出 1。它在真实 Chrome 中触发可见性处理器，不把该事件写成浏览器原生切换证据。

`8c2e9a7a` [主跑](main/summary.json)和[独立重跑](independent/summary.json)验证了保持权限时恢复草稿、冲突和撤权。随后[原生 Chrome 审查](native-review-failure/summary.json)观察到浏览器触发的可信隐藏和返回事件：普通切换与撤权通过，但在同一窗口切换期间收到的真实 PATCH 409 仍丢失草稿。HTTP 和 SQLite 均保持修订 3，属于界面恢复失败，而非服务端覆盖。此候选没有接受。

`1ce6e4f3` 修复了上述第二个缺陷。返回时先重新验证账号、固定来源及编辑权限；如果挂起期间服务端已保存同样的正文则不恢复待提交表单，如果当前修订已变且正文不同则保留草稿并要求人工核对。隐藏期间不重放写入。[最终主跑](final-main/summary.json)验证真实 HTTP 409、200 后回读、SQLite、迁移及撤权；它不是独立复核。
